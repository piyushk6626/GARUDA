# Aircraft Availability Forecast

Tool: `forecast_availability`

## Problem
Predict the probability each aircraft is mission-capable (FMC) at T+24/48/72 h, and expected fleet FMC count per base/type, so plans do not rely on aircraft likely to be down.

## Model
Gradient-boosted trees (XGBoost/LightGBM), binary classifier per horizon h: `P(FMC at t+h | features at t)`. Calibrated with isotonic regression. Fleet-level count = Σ p_i; variance via Poisson-binomial (or Monte Carlo) for confidence intervals.

## Features
type, age/flight hours, hours to next inspection, current status and time in status, maintenance ETA, sorties last 24/72 h, planned sorties (from plan), recent failure count, base, ground-crew load, spare-part availability flag, surge indicator, hour-of-day. Target: status at t+h from `aircraft_status_history`.

## Training data
Generated by the SimPy simulator (many replications with different seeds) - ~500k aircraft-hour rows. Time-based split (train early sim days, validate later), group k-fold by tail. Metrics: AUC, Brier score, calibration curve, fleet count MAE.

## Pseudocode
```
X = build_features(snapshot, planned_sorties)
for h in (24,48,72): p[h] = model[h].predict_proba(X)[:,1]
fleet_mean = p.sum(); fleet_ci = poisson_binomial_ci(p)
```
Deterministic override: aircraft with scheduled maintenance covering t+h => p = 0.

## Tool signature
```python
class ForecastAvailabilityInput(BaseModel):
    base_ids: list[str] | None = None
    types: list[str] | None = None
    horizons_h: list[int] = [24, 48, 72]
    include_planned_sorties_from: str | None = None   # plan_id

class ForecastAvailabilityOutput(BaseModel):
    per_aircraft: list[AircraftForecast]   # tail, {h: prob}, top drivers
    fleet: dict[str, FleetForecast]        # key base/type -> mean, p10, p90
    model_version: str
```
The MILP uses `avail_{a,t}` = thresholded or expected value (`p ≥ 0.7`, or chance-constrained).

## Explainability
SHAP top 3 drivers per aircraft (e.g. "42 h flown since last inspection").

## Failure modes
Distribution shift -> monitor calibration; fallback to rule baseline (current status + ETA).

## Libraries
xgboost/lightgbm, scikit-learn, shap, pandas; model registry in MinIO (`models/`), versions in Postgres.
