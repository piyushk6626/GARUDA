# Mission Success Probability

Tool: `predict_mission_success`

## Problem
Estimate the probability that a candidate package (aircraft, load, route, support) achieves the mission's required effect and returns, with explanation of the key drivers.

## Model
Gradient-boosted classifier (XGBoost) producing `P(success)`, plus a survival sub-score `P(return)`. Calibrated with Platt/isotonic. SHAP TreeExplainer for per-prediction contributions.

## Training data
Generated by an engagement-level Monte Carlo simulator (`monte_carlo_plan_evaluation`) run on randomly sampled packages: label = success (target effect achieved), survival. ~200k samples. Documented as synthetic ground truth, so ML learns a fast surrogate of the simulator (surrogate modelling) - enabling instant evaluation inside optimization loops.

## Features
Package: number of aircraft, types, weapons Pk (aggregate), SEAD presence, AAR support, stand-off range. Route: cumulative threat risk, minimum altitude, length, terrain masking fraction. Target: hardness, value, defended-by count. Environment: weather p_go, time of day. Resources: crew experience mean, fatigue max, aircraft risk (RUL).

## Pseudocode
```
X = featurize(package, route, target, weather, crew)
p_success = clf_success.predict_proba(X); p_return = clf_return.predict_proba(X)
shap = explainer(X) -> top +/- drivers
```

## Tool signature
```python
class SuccessInput(BaseModel):
    plan_id: str | None = None
    mission_id: str | None = None
    package: PackageSpec | None = None   # for what-if packages

class SuccessOutput(BaseModel):
    items: list[MissionSuccess]   # mission_id, p_success, p_return, ci_low, ci_high, drivers
    plan_expected_value: float
```
Used to set `pk_{c,m}` coefficients in MILP and for plan reports; also supports what-if ("add SEAD: +0.18").

## Validation
AUC/Brier on held-out simulator runs; calibration; monotonicity constraints in XGBoost (e.g. more SEAD never reduces success); agreement with direct Monte Carlo.

## Failure modes
Out-of-distribution packages -> detect via feature range check and fall back to direct simulation.
