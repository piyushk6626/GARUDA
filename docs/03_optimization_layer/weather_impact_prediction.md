# Weather Impact Prediction

Tool: `predict_weather_impact`

## Problem
Predict, per mission and base, the probability that weather will cause cancellation, abort, degraded effect (e.g. PGM guidance loss), or diversion, using forecast fields along the route and at base/target.

## Model
- Classifier: LightGBM multi-class or per-outcome binary (`GO`, `DEGRADED`, `NO_GO`), calibrated.
- Training labels from synthetic missions generated by rule-based simulator: thresholds (ceiling < 1500 ft at target for visual attack, visibility < 3 km, crosswind > 25 kt, CB along route, icing) plus noise and forecast error (forecast uncertainty grows with lead time, sigma ~ 0.1 per 12 h).
- Real forecasts from Open-Meteo used as features so the pipeline works end-to-end.

## Features
Base: ceiling, vis, crosswind, precip at launch/recovery (and alternates). Route: min flyability, fraction of route with CB, max headwind, icing indicator (temp in [−12, 0] with cloud). Target: low cloud, vis, aggregate. Lead time, mission type, weapon guidance type (laser/IR sensitive to cloud), time of day.

## Pseudocode
```
route_samples = sample(route, step=25km) -> times via speed
X = aggregate(weather(route_samples), base(launch), base(recovery), target)
p = model.predict_proba(X)   # [GO, DEGRADED, NO_GO]
suggest = best alternative window in next 12h maximizing p_go (sliding window scan)
```

## Tool signature
```python
class WeatherImpactInput(BaseModel):
    mission_id: str | None = None
    route: list[LatLon] | None = None
    launch_base: str
    recovery_base: str | None = None
    start_time: datetime
    aircraft_type: str
    weapon_guidance: Literal["LASER","GPS","IR","NONE"] = "NONE"

class WeatherImpactOutput(BaseModel):
    p_go: float
    p_degraded: float
    p_no_go: float
    limiting_factors: list[str]
    better_windows: list[TimeWindow]
    alternates: list[AlternateBase]
```
MILP uses `p_go` to filter/derate `ok_{a,c,m}`.

## Validation
AUC, calibration; backtesting forecasts against METAR observations at bases (real data check of flight category forecast accuracy).

## Failure modes
Missing forecast -> climatology; flag low confidence.
